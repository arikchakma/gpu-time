# gpu-time pipeline video

A 91-second, 1920×1080 / 60 fps explainer. The storyboard is in [`scenes.md`](scenes.md). The animation follows tokens through the model, role predictions, and calendar resolution into dates and recurrence rules.

Render the silent film (creates `video/.venv` on first run):

```sh
bash video/render.sh
```

Add narration, music, and the final mix:

```sh
bash video/render-voiceover.sh
```

`render-voiceover.sh` installs the voice dependencies and downloads the stock Kokoro `af_heart` model files into `video/output/tts-models/` if they are not already there. Requires Node.js 24+, FFmpeg, Geist Mono, and `uv`.

Publish the result to the website:

```sh
pnpm --filter @gpu-time/website prepare:video
```

Speech segments must fit their scene windows; event effects follow the render's motion timeline. The mixer measures speech levels, lowers music during speech, and limits the final peak without boosting the whole mix.

`data.json` is generated by `export-data.ts` and contains actual embeddings, recurrent states, classification-head activations, all logits, public outputs, and model and source hashes. The exporter compares diagnostic labels with the production tagger. It also reconstructs classifier scores independently to make sure that the trace matches.

The depicted architecture has 24,761 parameters, 324 embedding rows, 32 state channels, 16 head gates, 64 head hidden values, 40 role-output slots (35 named, five reserved), and one separate clause-boundary output. CPU f32 traces are shown; the same trained model also runs on WebGPU, but the animation is a schematic, not GPU profiling footage.

Outputs land in the ignored `video/output/`. The final file is `output/gpu-time-launch-voiceover.mp4`; English captions use measured speech endpoints. The source film is white and no inversion or color filter is applied.
